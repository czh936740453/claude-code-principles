核心术语表

看文章时遇到看不懂的词，来这里查。每个术语一句话解释，并指向详细章节。

Agent Loop代理循环第 03 章 →

核心 while 循环：感知 → 决策 → 行动 → 观察，直到任务完成。

Context Window上下文窗口第 06 章 →

一次请求里模型能「看到」的全部内容上限，单位是 token。

Token词元第 06 章 →

文本的最小计费/计长单位，中文大致 1 字 ≈ 1 token。

Compact压缩第 06 章 →

上下文快满时把旧消息浓缩成摘要，腾出空间继续工作。

System Prompt系统提示第 02 章 →

放在最前面、约束模型身份与行为规则的那段指令。

CLAUDE.md项目记忆文件第 02 章 →

放在项目根目录，每次会话自动读入上下文的项目说明。

tool_use工具调用请求第 04 章 →

模型返回的「我想调用某工具」的结构化消息。

tool_result工具执行结果第 04 章 →

工具执行完，把结果作为新消息放回上下文的动作。

Tool Registry工具注册表第 04 章 →

「工具名 → 函数」的映射表，模型只能调用登记过的工具。

YOLO权限分类器第 05 章 →

给工具调用按危险程度分级（LOW/MEDIUM/HIGH）决定放行还是询问。

Permission Mode权限模式第 05 章 →

default / acceptEdits / plan / bypassPermissions 四种全局策略。

allowlist / denylist白名单 / 黑名单第 05 章 →

手动指定哪些命令永远放行、哪些永远拒绝。

命令注入检查Command Injection Check第 05 章 →

在执行前检查命令是否试图绕过权限或注入危险操作。

Session会话第 06 章 →

一次对话的持久化记录，重启后可以恢复接着聊。

REPL交互式命令行第 07 章 →

Read-Eval-Print Loop：读输入 → 处理 → 输出 → 再读。

Slash Command斜杠命令第 07 章 →

以 / 开头的内置指令，如 /compact、/status、/init。

Feature Flag / Gate特性开关第 08 章 →

控制某个功能开不开启的开关，常用于灰度发布。

GrowthBook / tengu_*灰度发布系统第 08 章 →

Anthropic 内部用的特性门控命名空间（tengu_*）。

anthropic-beta 头Beta 请求头第 08 章 →

HTTP 头，声明要启用的实验性 API 能力。

Source Map源码映射第 09 章 →

打包产物与原始源码的映射文件，泄露源头就在 cli.js.map。

PARITY移植对齐第 09 章 →

Rust 移植版与原始行为逐项对齐的清单/思路。

CrateRust 包第 09 章 →

Rust 的模块化单元，相当于一个库或可执行程序。

Agent代理拓展篇 →

能感知、决策、行动、观察并循环的自主程序，而不是一次性问答。

Harness代理外壳拓展篇 →

除了模型本身之外的一切工程代码：循环、工具、权限、上下文、记忆、CLI 等，把模型变成能动手的 Agent。

Workflow工作流拓展篇 →

步骤写死的固定流程，与运行时自主决策的 Agent 相对。

Subagent子代理拓展篇 →

有独立角色与上下文的小代理，主代理把任务分包给它再回收结果。

Memory记忆拓展篇 →

Harness 给模型配的短期（上下文）与长期（CLAUDE.md、会话文件）记忆。

Hook钩子拓展篇 →

在固定时机（如工具调用前后）触发外部脚本的机制，让 Harness 行为可编程。

MCP模型上下文协议拓展篇 →

接入外部工具 / 数据源的标准协议，相当于 Harness 的「万能插口」。
