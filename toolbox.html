mini_agent.py第 01 章 · 认识 Claude Code →

认识「代理」的最小雏形：一个读目标 → 决定 → 动手 → 看结果的循环骨架。

运行：python mini_agent.py
agent_loop.py第 03 章 · 代理循环 Agent Loop →

最小可运行的代理循环：模拟模型返回工具调用，循环执行直到完成。

运行：python agent_loop.py
tools.py第 04 章 · 工具系统 →

工具注册表 + 调度器：工具 = 名字 + 说明 + 函数，模型只能调用登记过的工具。

运行：python tools.py
permissions.py第 05 章 · 权限与安全 →

YOLO 式风险分级器骨架：按命令危险程度决定放行 / 询问 / 拒绝。

运行：python permissions.py
session.py第 06 章 · 会话与上下文管理 →

会话保存 / 恢复的最小实现：把消息历史序列化成 JSON 存盘，下次读回来。

运行：python session.py
context_manager.py第 06 章 · 会话与上下文管理 →

token 估算 + 压缩触发：计算上下文占用，超过阈值自动把旧消息压成摘要。

运行：python context_manager.py
cli_repl.py第 07 章 · CLI 与斜杠命令 →

极简交互式 REPL：提示符 → 读输入 → 解析斜杠命令 → 响应 → 循环。

运行：python cli_repl.py
config.py第 08 章 · 配置、环境变量与特性门控 →

环境变量解析 + 特性开关：用环境变量覆盖默认值，控制功能开不开。

运行：python config.pyCLAUDECODE_COORDINATOR_MODE=1 python config.py
codex_bridge.py第 10 章 · 自学路线图与实践建议 →

本机 Codex 直连桥接服务：让网站的「问 Codex」窗口真正调用本机 Codex CLI（只读沙箱，仅本机流转）。

运行：python tools\codex_bridge.pypowershell -ExecutionPolicy Bypass -File tools\start_bridge.ps1
