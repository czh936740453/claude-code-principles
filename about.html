关于本站

这个站是给自学者准备的 Claude Code 原理图解，目标是「看得懂、跑得起来、能自己动手」。

/内容来源

  • ccleaks.com/leaks —— 对 Claude Code 公开源码的分析汇总：8 个未发布特性、26 个隐藏命令、32 个构建开关、120+ 环境变量等。
