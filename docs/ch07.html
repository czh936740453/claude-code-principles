07 · CLI 与斜杠命令

掌握 Claude Code 的「人机界面」：启动方式、交互模式、斜杠命令与隐藏命令。

本章目标　掌握 Claude Code 的「人机界面」：启动方式、交互模式、斜杠命令与隐藏命令。前置依赖　建议先读第 2 章。

07 /REPL：你看到的最小界面

你在终端里和 Claude Code 交互的那个输入框，本质上是一个 REPL：Read（读输入）→ Eval（处理）→ Print（输出）→ Loop（循环）。它并不神秘——就是一个 while 循环里反复「读一行输入 → 处理 → 打印结果」。

运行 python cli_repl.py，输入 hello、/help、/status、/quit 感受一下。你会发现：斜杠命令和普通对话走的是两条分支。

07 /斜杠命令：内置指令

在 REPL 里输入以 / 开头的命令，就会触发内置指令。常见的公开命令有这些：

命令作用说明
/help查看帮助列出全部命令
/init初始化项目生成 CLAUDE.md
/compact压缩上下文手动触发压缩（第 6 章）
/status查看会话状态会话信息、上下文占用
/context查看上下文当前上下文里有什么
/model切换模型选择 opus / sonnet 等
/config打开配置编辑 settings.json
/doctor自检检查安装和环境
冷知识公开源码分析里发现了 26 个隐藏斜杠命令——它们没有出现在帮助文档里，属于内部 / 实验功能，比如 /statusline（自定义状态栏）、/buddy（宠物彩蛋）等。命令本身未必都能用，但能看出团队在实验什么。

1. REPL 中的「L」代表什么？

Read-Eval-Print-Loop：读、处理、输出、循环，是交互式命令行的基本形态。 回看：REPL

2. 隐藏斜杠命令和普通命令的区别是？

26 个隐藏命令不显示在帮助文档中，属于内部实验功能。 回看：斜杠命令

3. 斜杠命令和普通对话在 REPL 里是什么关系？

REPL 读入一行后先判断是否以 / 开头，分别进入指令分支或对话分支。 回看：斜杠命令
本章小结
  • 交互界面 = REPL：读输入 → 处理 → 输出 → 循环。
  • 斜杠命令和普通对话走不同分支，/ 开头触发内置指令。
  • 公开分析发现 26 个隐藏命令，多为实验功能。
✗ 误区：以为斜杠命令只有 /help 里那几条
✓ 真相：源码里还有 26 个隐藏命令，比如 /compact、/status、/context 等，/help 不展示它们。
✗ 误区：以为 REPL 很神秘
✓ 真相：REPL 就是一个 while 循环：读输入 → 处理 → 输出 → 再读。
✗ 误区：以为斜杠命令是给模型用的
✓ 真相：斜杠命令是你（人类）在输入框里敲的快捷指令，用来控制程序行为。
