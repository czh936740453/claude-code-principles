进阶篇 · 精读真实代码：三个 Agent 循环

把第 3 章的「代理循环」放到真实代码里：精读 OpenAI Agents SDK、smolagents、claw-code 三个项目的循环实现，逐句看懂。

进 /读代码的正确姿势

别一上来就逐行读。三步走：先找入口 → 再找循环 → 最后追数据。

  1. 找入口：程序从哪开始？（Runner.run / agent.run / main）
  2. 找循环：哪个 while / for / step 在反复执行？
  3. 追数据：messages / context / 记忆是怎么一步步被改写的？
心法读代码读到「哦，这就是第 3 章那个循环」就成功了，其余细节可以之后再补。

smolagents 把「循环的一步」写成一个方法 step()，注释一句话就说清了 ReAct：

解读三件事：

  • 返回值：返回 None = 还没结束、继续下一轮；返回答案 = 这是最后一步（这就是终止条件）
  • _step_stream：一个生成器，一步步产出「思考 → 行动 → 观察」，[-1] 取最后一步

进 /精读 ③ claw-code（Rust）：顺序子代理

claw-code 的 agents 子命令做的不是「一个循环」，而是多个子代理的顺序编排：把一个大任务拆给几个专用 Agent（如 audit / explain / implement），依次跑完。核心是这段 Rust：

解读：

  • specs.into_iter().enumerate()：逐个取出 Agent 配置（名字、preset、权限、模型）
  • run_one(cfg, &mut buf).await：每个 Agent 内部都有一个完整的代理循环（就是第 3 章那个！），跑完把输出写进 buf
  • tail_chars(..., 1600)：只保留结果尾部 1600 字符作为摘要，避免把完整输出都传给下一个环节
多智能体 = 多个循环 + 串起来单个 Agent 的循环没变，变的是「循环之外」：谁先跑、结果传给谁、共享什么上下文。

本章小结
  • 读代码三步：找入口 → 找循环 → 追数据
  • Agents SDK：循环藏在 Runner.run 里，官方注释就是「官方版伪代码」
  • smolagents：step() 一步一 ReAct，返回 None 继续、返回答案结束
  • claw-code：顺序子代理编排 = 多个循环 + 共享上下文串起来
  • 三个循环本质相同：都是「感知 → 决策 → 行动 → 观察」
✗ 误区：真实源码比教程复杂一百倍、肯定看不懂
✓ 真相：骨架就是第 3 章的循环；生产代码只是加了护栏、追踪、会话这些「外层」。
✗ 误区：注释不重要，代码才重要
✓ 真相：Agents SDK 的循环描述就写在注释里，官方注释是最优质的一手资料。
✗ 误区：多智能体 = 一套全新的循环
✓ 真相：单个循环没变，变的是「循环之间怎么串」。
