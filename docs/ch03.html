03 · 代理循环 Agent Loop

掌握 Claude Code 的心脏——while 循环：感知、决策、行动、观察，循环往复直到完成。

本章目标　掌握 Claude Code 的心脏——while 循环：感知、决策、行动、观察，循环往复直到完成。前置依赖　建议先读第 2 章。

03 /核心：一个 while 循环

Claude Code 的心脏非常朴素——一个 while 循环。翻译成大白话就是：只要还没干完，就一直干下去。每一次循环做四件事：

  1. 感知看看当前状态：任务是什么、已经做到哪一步、上一步的结果是什么。
  2. 决策把状态交给模型，让模型决定下一步：继续说、还是调用工具。
  3. 行动如果要调用工具，就在本地执行它。
  4. 观察把工具结果放回上下文，回到第 1 步。

用伪代码写出来就是这样（注意 while 和 continue）：

试着走一轮代理循环（点击“下一步”）

01感知读取当前状态
02决策模型决定下一步
03行动调用工具
04观察结果回填上下文

03 /为什么它叫「代理」而不是「问答」

聊天机器人只执行一次「输入 → 输出」。代理把这个过程循环起来，并且每一步都能观察结果再决定下一步——所以它能处理多步骤、需要动手的任务。有没有工具、能不能循环，是代理和聊天的分水岭。

03 /什么时候结束：终止条件

循环不能永远跑下去，Claude Code 靠三种方式结束：

  • 模型主动结束：模型返回普通文本（不再要求调用工具），认为任务完成。
  • 达到上限：步数上限、token 预算用尽，强制停止。
  • 用户打断：Ctrl+C 或输入 /quit 退出。
